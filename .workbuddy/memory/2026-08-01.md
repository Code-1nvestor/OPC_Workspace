### 关键技术决策（值得记忆）
- Electron 内嵌 Express 时，dev 模式必须用固定端口 3000（Vite proxy 写死了），prod 用动态端口 0
- ESM `import()` 路径在 Windows 必须用 pathToFileURL 转 file:// URL
- server bundle 时把 native 包（better-sqlite3）和大依赖（express/@tencent-ai/agent-sdk/uuid）标 external，运行时解包到 asar.unpacked
- better-sqlite3 在 Windows 上打包 Electron 必须 electron-rebuild，否则 ERR_DLOPEN
- 沙箱环境（WorkBuddy 内置终端）会注入 ELECTRON_RUN_AS_NODE=1 + NODE_OPTIONS=--require=safe-delete.shim，必须清理后才能跑 Electron
- node 内置 safe-delete shim 会在 rmSync 时拦截，但 export NODE_OPTIONS="--use-system-ca" 可以绕过（仅去掉 safe-delete 但保留 TLS）
